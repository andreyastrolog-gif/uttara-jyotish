# Uttara Jyotish — сайт ведического астролога Андрея

Одностраничный статический сайт (HTML + CSS + немного JS, без сборки и зависимостей). Светлый минималистичный дизайн, адаптивный (проверен на 1440 px и 390 px), с SEO-разметкой.

Сейчас опубликован на GitHub Pages: https://andreyastrolog-gif.github.io/uttara-jyotish/

## Что где лежит

| Файл / папка | Назначение |
|---|---|
| `index.html` | Вся страница: тексты, мета-теги, Open Graph, JSON-LD (Person, Service, FAQPage) |
| `css/style.css` | Стили (цвета и шрифт настраиваются в `:root` в начале файла) |
| `js/main.js` | Ссылки на соцсети (блок `LINKS` в начале), мобильное меню, плавное появление блоков, FAQ |
| `fonts/manrope.woff2` | Шрифт Manrope (локально, без Google Fonts) |
| `img/andrey-desk*.jpg/.webp` | Фото Андрея (1200 px и 800 px) |
| `img/emblem-160.webp` | Логотип для шапки и подвала |
| `img/og-image.jpg` | Картинка для превью ссылок в соцсетях и мессенджерах (1200×630) |
| `favicon*.png`, `favicon.ico`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest` | Иконки сайта |
| `robots.txt`, `sitemap.xml` | Для поисковых систем |
| `.nojekyll` | Нужен только для GitHub Pages |

## Что нужно заполнить (заглушки)

1. **Ссылки.** Откройте `js/main.js` и впишите адреса в блок `LINKS`:
   - `telegram` — личный Telegram для записи (например `https://t.me/username`) — все кнопки «Записаться»;
   - `telegramChannel` — Telegram-канал;
   - `instagram`, `youtube`, `tiktok`, `facebook`.

   Для надёжности (поисковики не всегда выполняют JS) сделайте ещё поиск-замену в `index.html`:
   `#TELEGRAM_LINK`, `#TELEGRAM_CHANNEL_LINK`, `#INSTAGRAM_LINK`, `#YOUTUBE_LINK`, `#TIKTOK_LINK`, `#FACEBOOK_LINK`.
2. **Домен.** Замените `https://example.com` на свой адрес сайта во всех местах: `index.html` (canonical, og:url, og:image, twitter:image, JSON-LD), `robots.txt`, `sitemap.xml`.
3. **Цены** — сейчас везде «Стоимость — по запросу». Если захотите указать цены, правьте тексты в разделе «Консультации» и ответ в FAQ (в двух местах: видимый текст и JSON-LD в `<head>`).
4. По желанию: отзывы, образование/опыт, даты ближайшего потока курса — на сайте намеренно нет выдуманных цифр и отзывов, добавляйте только реальные.

## Как загрузить на свой хостинг

1. Заполните заглушки (см. выше).
2. Загрузите **всё содержимое папки** (кроме `.git` и `README.md` — их можно не загружать) в корневую папку сайта на хостинге (обычно `public_html` или `www`) через файловый менеджер панели хостинга или по FTP/SFTP (например, FileZilla).
3. Подключите HTTPS (бесплатный сертификат Let's Encrypt есть почти у всех хостингов).
4. Проверьте: сайт открывается, кнопки ведут в Telegram, превью ссылки в мессенджере показывает картинку.
5. Добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте `sitemap.xml`.

Подойдёт любой хостинг статических файлов: обычный виртуальный хостинг, Netlify, Cloudflare Pages, GitHub Pages. Серверные языки и база данных не нужны.

## Как обновлять фото

Замените `img/andrey-desk.jpg` / `.webp` (1200 px по ширине) и `img/andrey-desk-800.jpg` / `.webp` (800 px), сохранив пропорции 4:3 (или поправьте `width`/`height` в `index.html`).
