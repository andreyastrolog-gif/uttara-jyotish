# Uttara Jyotish — сайт ведического астролога Андрея

Статический сайт (HTML + CSS + немного JS) на трёх языках — русский (`/`), украинский (`/uk/`), английский (`/en/`) — и блог. Светлый минималистичный дизайн, адаптивный (проверен на 1440 px и 390 px), с SEO-разметкой.

**Все HTML-файлы, `sitemap.xml`, `robots.txt` и RSS генерируются** скриптом `/workspace/site/work/build.py` (вне репозитория). Руками их не правьте — изменения затрутся при следующей сборке. Тексты — в `/workspace/site/work/i18n/{ru,uk,en}.py`, статьи блога — в `/workspace/site/work/blog/posts/<язык>/*.md` (инструкция: `/workspace/site/work/blog/README.md`).

Сейчас опубликован на GitHub Pages: https://andreyastrolog-gif.github.io/uttara-jyotish/

## Что нужно заполнить (заглушки)

1. **Ссылки.** Откройте `js/main.js` и впишите адреса в блок `LINKS`:
   - `booking` — бот записи `https://t.me/andreyastrologbot?start=site` — все кнопки «Записаться» (заявки приходят Андрею в Telegram, он отвечает через Reply);
   - `telegram` — личный Telegram (`https://t.me/andreyastrolog`) — кнопка «Написать мне в Telegram» и ссылка в футере;
   - `telegramChannel` — Telegram-канал;
   - `instagram`, `youtube`, `tiktok`, `facebook`.

   Бот и личный Telegram задаются в `/workspace/site/work/config.py` (`BOT`, `TG`) и дублируются в `js/main.js`.
   Соцсети (заглушки `#INSTAGRAM_LINK` и т.п.) — в `js/main.js`; для надёжности (поисковики не всегда выполняют JS) их можно также вписать в `SOCIAL` в `build.py`.
2. **Домен** — см. раздел «Свой домен» ниже.
3. **Цены** — сейчас везде «Стоимость — по запросу». Если захотите указать цены, правьте тексты в разделе «Консультации» и ответ в FAQ (в двух местах: видимый текст и JSON-LD в `<head>`).
4. По желанию: отзывы, образование/опыт, даты ближайшего потока курса — на сайте намеренно нет выдуманных цифр и отзывов, добавляйте только реальные.

## Языки

- Русский — в корне `/`, украинский — `/uk/`, английский — `/en/`. На каждой странице `<html lang>`, `hreflang` (ru, uk, en, x-default = ru) и переключатель RU / UA / EN в шапке (и на мобильном) и в подвале.
- **Автовыбор языка**: только при первом заходе на корневую страницу и только если язык ещё не выбран вручную. Скрипт смотрит `navigator.languages`: украинский → `/uk/`; русский, а также be, kk, ky, tg, uz, tk, hy, az, ka, mn → остаётся на русском; английский и любые другие языки → `/en/` (берётся первый распознанный язык в списке браузера). Переход — `location.replace` с сохранением `#якоря`.
- Выбор в переключателе сохраняется (`localStorage.uj_lang`) и всегда соблюдается: например, выбрав UA, человек при заходе на `/` попадёт на `/uk/`.
- Поисковые роботы не перенаправляются (скрипт пропускает известных ботов), для них есть `hreflang` и sitemap с альтернативами.
- Тексты: `/workspace/site/work/i18n/ru.py`, `uk.py`, `en.py` (одинаковая структура). Шаблон — `build.py`.

## Свой домен

Адрес сайта задаётся в ОДНОМ месте — `BASE_URL` в `/workspace/site/work/config.py` (сейчас `https://andreyastrolog-gif.github.io/uttara-jyotish`). Из него строятся canonical, hreflang, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt` и RSS. Все внутренние ссылки на сайте относительные, поэтому на новом домене они заработают без правок.

1. В `config.py`: `BASE_URL = 'https://ваш-домен.com'` и `CNAME_DOMAIN = 'ваш-домен.com'` (для GitHub Pages — скрипт создаст файл `CNAME`).
2. `./publish.sh "Switch to custom domain"`.
3. У регистратора домена: для корневого домена — A-записи на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (или CNAME `www` → `andreyastrolog-gif.github.io`).
4. GitHub → Settings → Pages → Custom domain → ваш домен, включить «Enforce HTTPS».
5. Добавить сайт в Google Search Console и Яндекс Вебмастер, отправить `https://ваш-домен.com/sitemap.xml`.

Если переезжаете на обычный хостинг — шаг 1 без `CNAME_DOMAIN`, соберите и загрузите содержимое папки (см. ниже).

## Как загрузить на свой хостинг

1. Заполните заглушки (см. выше), поменяйте `BASE_URL` и соберите сайт.
2. Загрузите **всё содержимое папки** (кроме `.git` и `README.md` — их можно не загружать) в корневую папку сайта на хостинге (обычно `public_html` или `www`) через файловый менеджер панели хостинга или по FTP/SFTP (например, FileZilla).
3. Подключите HTTPS (бесплатный сертификат Let's Encrypt есть почти у всех хостингов).
4. Проверьте: сайт открывается, кнопки ведут в Telegram, превью ссылки в мессенджере показывает картинку.
5. Добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте `sitemap.xml`.

Подойдёт любой хостинг статических файлов: обычный виртуальный хостинг, Netlify, Cloudflare Pages, GitHub Pages. Серверные языки и база данных не нужны.
